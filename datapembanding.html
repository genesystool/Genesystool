Cara Mengambil Data dari SIK NG

FILE 1

Periode Sebelumnya (Patokan)

  • Buka Menu Monitoring → Pilih Semua Cluster.
  • Pilih Bansos PKH.
  • Pilih Periode Sebelumnya (Misal: Tahap 2).
  • Status Salur: Pilih Sudah Transaksi.
  • Download data (Format CSV).
FILE 2

Periode Berjalan (Pembanding)

  • Buka Menu Monitoring → Pilih Semua Cluster.
  • Pilih Bansos PKH.
  • Pilih Periode Berjalan/Sekarang (Misal: Tahap 3).
  • Status Salur: Pilih Sudah SI (Atau status dengan data terbanyak).
  • Download data (Format CSV).
